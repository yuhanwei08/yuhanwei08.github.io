About Me

I am an MSc Robotics student at The University of Manchester, with a Bachelor of Engineering in Electronic Information Science and Technology from Nanjing Agricultural University. My interests lie in computer vision, embedded systems and their applications in robotics.

Through individual and team projects, I have gained experience in image classification, object detection, robot control and application development. My work has included developing a CNN-based chrysanthemum recognition application, contributing to vision-based agricultural inspection projects, and implementing navigation and sensing functions for a line-following robot. At Manchester, I hope to deepen my knowledge of robot perception and autonomy.

An Edge Computing-Based Egg Collection Conveyor Belt System for Online Egg Inspection

Overview

This team project developed an online egg inspection system for collection conveyors. YOLOv5 detected and classified eggs, while DeepSORT maintained target identities for tracking and counting. The models were deployed on Jetson Nano, with inspection results and historical records displayed through a web platform. Conveyor speed and detection timing were also used to estimate the source cage of detected eggs.

My Contribution

  • Helped test and debug DeepSORT-based egg tracking and line-crossing counting, checking for duplicate and missed counts.
  • Compared automated counts with manual records and evaluated counting accuracy, classification errors and processing speed.

Key Features

  • YOLOv5-based egg detection and classification.
  • DeepSORT tracking and line-crossing counting.
  • Camera-based image acquisition and edge deployment on Jetson Nano.
  • Web-based inspection results, historical records and data visualisation.
  • Source-cage estimation using conveyor speed and detection timing.

Technologies

Python · PyTorch · YOLOv5 · DeepSORT · Jetson Nano · Vue · Spring Boot

Line-Following Robot for Poultry Farm Monitoring

Developed a three-person coursework prototype for poultry-house inspection, combining STM32 motion control, OpenMV vision and environmental sensing. The system was demonstrated on a marked indoor course, with a model chicken used for the vision demonstration.

My Contribution

  • Designed the overall system architecture and inspection route, and connected and debugged the robot hardware.
  • Implemented four-sensor line following, PWM motor-speed control and ultrasonic obstacle-avoidance functions.
  • Adapted and refined OpenMV image acquisition and processing code for model-chicken detection.
  • Tested the inspection route and adjusted control delays, sensor sensitivity and hardware connections to improve cornering.

Key Features

  • Black-line navigation with straight-line travel and turning, using four reflectance sensors and PWM motor control.
  • Ultrasonic distance sensing for obstacle avoidance.
  • OpenMV vision for model-chicken detection and image-coordinate output.
  • Temperature, humidity, CO₂, light and thermistor readings, with an OLED display and Bluetooth/serial communication.
